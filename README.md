# 🧠 CodersYap

**Nerd rants from a not-so-quiet mind.**  
A developer blog built with love, Next.js, Tailwind CSS, and MDX.

---

## 🚀 About

CodersYap is a personal tech/dev blog where I document the chaos that happens when a "we ball" moment and "it's so over" moment happens.  
It’s a space for tutorials, experiments, failures, rants, and moments-of-wisdom.

---

## 🛠️ Tech Stack

- **Next.js** — Framework for the web
- **Tailwind CSS** — Utility-first styling
- **MDX** — Write Markdown + React components
- **Giscus** — GitHub-powered comment system
- **Lenis** — Smooth scroll because smooth scroll
